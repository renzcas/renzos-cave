# Renzoverse Integration — World Layer

## Purpose
Renzoverse is the world layer of the unified architecture. It provides:
- regions
- biomes
- entities
- lore
- world scripts (CaveSharp)

## Engine Integration
Renzoverse exports world data consumed by SovereignEngine-Core:
- regions.json
- entities.json
- biomes.json

## CaveSharp Integration
World scripts define:
- region events
- entity behaviors
- environmental triggers

## Organism Integration
BIG_ANIMAL creatures may appear inside Renzoverse regions.

## Cockpit Integration
Renzo-Hacker-Lab can send CaveSharp commands to manipulate world state.

## Visualization
AgentDash displays:
- region metrics
- entity activity
- world events
